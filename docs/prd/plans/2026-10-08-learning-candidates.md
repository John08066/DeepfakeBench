## 固定输入与共同评估

- `x` 为现有输入，`P` 为VAE内部预处理往返，`G` 为完整冻结VAE；`z=f(x)∈R^1024`，`u=unit(f(Px)-f(Gx))∈R^1024`。除Q19明确改变适配器共享方式，编码器均沿用Q10的共享CLIP+LoRA；encoder eval但LoRA有梯度，VAE冻结。Adam、学习率、batch、配对seed和增强沿用Q10已验收设置，不扫常规超参。
- Q18/Q19/Q20各两条新训练臂，均fresh初始化、12轮/21576更新，使用Q10的FF++ c23训练清单、源划分和每步增强/头RNG配对规则。源val每轮一次，以balancedCE最低选source_best、平局最早；固定terminal同时报告，不按目标结果换点、改损失或延长。
- source_best与terminal均评估Q10同一700源视频及5876目标视频、每视频至多8帧、平均logits；逐域报告AUC/普通CE/balancedCE。训练及选点只用源数据。目标三域已反复用于开发，今后结果仍称开发验证；源test也不是未触碰测试。正式方法主张还需另行封存的未参与设计评估，不把重复开发结果包装为独立最终验证。
- **仅对本页新训练生效**：唯一主端点为source_best的三目标域宏视频AUC。相对本项指定主控制，`ΔAUC≥0.005`且2000次按域/类别分层的视频配对bootstrap 95%下界>0，才支持固定预算下的开发排序收益；点差≤0未支持，其余不确定。0.005是预设工程效应门槛，不是显著性水平。CE、分域和terminal必须并列报告，不用其中最好的一项替换主端点；宏提升但部分域退步不能称一致跨域收益。
- 这些区间只反映固定权重/清单下的视频抽样不确定性，不含训练重复与未知人物/源视频族相关性。源AUC保留为描述，不再要求接近1的基线额外提高0.01。本页不修改已登记的Q10/Q12/Q13/Q14等旧判据。

- 主比较的两新臂必须同机同软件/输入协议配对；不拼接203/4090不同训练充当严格主对照。旧Q10无辅助头/无蒸馏模型可作背景；只有初始化、数据、完整trace及实现/环境配对可核实时才作额外严格对照，否则明确背景性质，不临时补训第三臂。每组代码/配置与终态结果分别中文Git；训练代码不push，认领与结果协作文档按用户授权发布并读回。

## <a id="q17-d01"></a>Q17-D01：分支学习与选点敏感性诊断

**问题**：Q10增量在source_best上的目标AUC收益，为何到terminal反转？原图直通与整体残差路径是否表现出可定位的学习竞争？本项提供后续设计依据，不从现有目标数据重新挑一个最好模型。

- 复用Q10 original/joint及Q13 total的source_best/terminal预测、12点源val曲线、预定2/4/8/12轮192开发曲线；不重新跑全目标GPU评估。按视频对齐后报告固定端点差、逐域误差重叠及每视频CE变化分布。source_best/terminal与192/5876两种覆盖分别比较，不混清单，也不将标签选择的oracle组合称可部署性能。
- 仅在Q10 joint的source_best和terminal上，沿第一轮已存trace等间距取32个batch索引并在认领时保存，eval模式、无增强，0参数更新。对同一个联合分类损失，分别阻断另一路梯度，取得共享LoRA参数上的`g_z=∂L/∂θ|原图直通`与`g_u=∂L/∂θ|完整残差路径`；记录范数、内积、非零时夹角及按既有伪造方法的分布。需验证`g_z+g_u`重构总梯度。这是固定checkpoint/eval损失的局部梯度，不是训练时梯度轨迹重放。绝不把残差两端相减自然产生的反号，当成原图/残差分支竞争。
- 负夹角不等于有害，范数小不等于没信息；这里只识别干预位置，后续Q19的匹配训练才检验解耦是否有益。零范数如实记未定义角度，不删样本。只报告固定统计，不按目标收益挑batch、权重或梯度阈值。
- **总墙钟≤2h，其中GPU≤1h、CPU≤1h；新产物及备份≤1GiB，0训练更新、0新checkpoint。** 输入必须与既有归档一致，缺权重/曲线则明确缺项，不补造或自动重训。其结果不阻塞可独立设计的Q18；若看不到稳定竞争证据，Q19降优先级，不据此证明解耦无效。
- 查重：P03-D01是固定头响应贡献，Q08是线性可读性，Q05/N06改变梯度路径；均未给出这次12轮严格配对的端点翻转与`g_z/g_u`诊断。

## <a id="q18-t01"></a>Q18-T01：残差分支直接监督

**假设**：联合分类头容易依赖原图；直接约束残差可读性，比一般性的额外原图监督更有用。不是预设“残差有新信息”。

- 两臂同Q10联合头`h([z,u])`和额外1024→2线性辅助头`a`（2050参数、相同初始化）。残差监督臂：`L=CE(h([z,u]),y)+CE(a(u),y)`；原图辅助控制：`L=CE(h([z,u]),y)+CE(a(z),y)`。CE沿用基线标签/计权口径，系数固定1，不扫描损失权重；相同训练参数量、batch和更新数，推理都移除辅助头。
- 唯一主比较是残差辅助对原图辅助，使用共同新判据；Q10无辅助头仅按复用条件作额外对照。记录源train固定batch上的辅助读出及两条梯度路径是否真正更新，不把增加了一个损失就称实现分支监督。
- 若只比旧无辅助头好、却不胜同容量原图辅助，不支持残差特定监督优势；若仅辅助头好而部署的联合头无收益，不把训练诊断当提点。两新臂比较阳性且旧对照无法严格复用时，只能声称优于该原图辅助方案，不能声称已经严格超越原PRD。
- **优先长训，可独立于Q12/Q14认领设计**；按共同两臂12轮/48 GPUh候选上限。N04的残差单支分类与Q05的适配实验没有这组联合主头下的辅助监督控制，不重复旧原图/残差消融矩阵。

## <a id="q19-t01"></a>Q19-T01：等总参数的原图/残差适配器解耦

**假设**：同一套LoRA同时服务原图语义与重建响应，限制了两者互补；保留残差两端共享、但将原图直通的适配器分开可能改善联合学习。Q17仅提供定位证据，不是该因果结论。

- 两臂fresh并同2048维联合头。共享控制：三个前向使用同rank=`R` LoRA。解耦臂：`z=f_A(x)`，`u=unit(f_B(Px)-f_B(Gx))`，A/B各rank=`R/2`，冻结CLIP主干仍共享；保持alpha/r缩放一致。`R`取实际基线登记值，实施前核验为偶数且两臂总可训练参数确实相同；不是rank扫描。
- A/B适配器初始化使LoRA增量均为零，故初始函数相同；共享控制的降维因子按行拼接两半适配器的初始降维因子，各升维因子为零，映射在运行代码登记。残差两端必须共用B，不能变成两个不同坐标系相减。原图梯度只更新A，残差路径只更新B；禁止增加第三适配器、门控网络或额外损失。报告每路径容量、实际FLOPs与耗时，等总参数不等于函数类或算力完全相同。
- 唯一主比较解耦对共享，采用共同新判据。若只有源训练损失改善而主端点无收益，停止此解耦方案；不凭梯度夹角转正宣称机制成立。Q17若没有竞争线索，本项转低优先，不自动增加解耦层/rank组合。
- **条件长训**：Q17归档后确定优先级；共同两臂12轮/48 GPUh候选上限。不同于N06停止残差梯度，也不同于Q05固定一个重建端点；本项保留完整残差学习，改变参数共享约束。

## <a id="q20-t01"></a>Q20-T01：训练期重建探针蒸馏到单视图学生

**假设**：PRD教师可能通过训练监督传递重建响应的判别偏好，学生推理不再需要VAE及额外图像前向。蒸馏本身不是新技术，需检验收益是否来自PRD教师而非任意教师。

- 固定两个已有教师：Q10 joint/source_best与original/source_best；不按目标挑教师，不更新教师。两学生均fresh原图CLIP+LoRA、同Q10原图头和初始化；训练分别使用PRD教师或原图教师，`L=CE(student(x),y)+KL(teacher(x)||student(x))`，温度1、系数1固定，KL按类别求和后batch平均。教师eval、stop-gradient，监督仅用源train。
- 两学生使用相同增强输入/头RNG/更新预算；PRD教师在该增强图像上执行P/G及联合前向，不能用未增强教师输出冒充配对。可缓存确定性同trace的教师logits，缓存生成成本计入本组，禁止引入目标标签或目标域蒸馏。学生推理均仅原图一路。
- 唯一主比较PRD教师学生对原图教师学生，采用共同新判据；无蒸馏Q10原图按复用条件作额外对照。还必须在同设备、同batch、相同计时口径报告学生与PRD教师的完整推理时延和峰值显存，包含VAE和所有前向。相对PRD教师的AUC损失若超过0.005，即使学生间主比较通过，也不声称“基本保留教师性能”。
- 若原图教师蒸馏同样有效，则不支持探针特有迁移；如果只降成本却明显损失检测能力，报告真实精度/成本折中。成功也不能证明学生恢复了重建器内部机制。
- **后续长训**：Q17先归档，确认教师、固定端点与输入可复用；共同两臂12轮/48 GPUh候选上限（包含教师成本）。不等待Q18/Q19挑赢家，不做教师/温度/蒸馏层扫描。
