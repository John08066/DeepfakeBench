## 共用边界

- 不更换 Adam、学习率、训练 batch 或配对 seed，不扫描算子强度、层数、步长。端到端训练沿用所属分支已验收配置；冻结小头沿用 [Q04](../records/Q04-T01.md) 已验收的拟合设置，二者不混称同一训练配置。
- `x` 为现有 224×224 输入；`P(x)` 为现行 VAE 内部预处理往返、跳过 encode/decode；`G(x)` 为完整冻结 VAE；`B(x)` 用既有固定 sigma=1 blur 替代 encode/decode，其余往返相同。`f` 为输出 1024 维的 CLIP，所有视图共享同一编码器；`unit` 沿用既有实现，不调 epsilon。图像中点在统一浮点图像空间计算，再作同一 CLIP 输入处理。
- Q14/Q15/Q16 只冻结编码器提特征、拟合小头。复用 Q04 的源 train/val/test 3596/700/700 视频、每视频同一字典序首帧；固定线性头 500 更新、每 10 步源 val balanced CE 选点、平局最早，逐维标准化只拟合源 train。各臂零初始化、同选择机会。Q14 须用相同输入清单重新提取其指定 checkpoint 特征，不能混用 Q04 编码器缓存。
- 冻结探针每项总计 **≤4 小时墙钟，其中 GPU≤3 小时、CPU≤1 小时，新缓存及备份合计≤2GiB**，包括 smoke、提取、所有头、评估与归档；0 编码器更新、0 自动重试。首批测速无法覆盖完整对照即停止预检，不删对照凑预算。Q13 的预算另列。
- 主结果仅为预先固定的源 test 比较：候选相对指定控制 `ΔbalancedCE=CE控制−CE候选≥0.02 nat`、`ΔAUC=AUC候选−AUC控制≥0.01`，且 70 源/供体连通分量的 2000 次配对 bootstrap CE 95% 下界>0。要求多个控制时全部通过；任一主比较点差≤0为未支持，其余未达条件为不确定。各比较完整报告，不从多个头挑赢家替换主假设。
- 原 192 目标视频只作开发描述，不用于拟合、选方案或触发追加；源 test 也已多次使用，不能称未触碰的最终测试。冻结可读性不代表端到端收益；阴性结果只降低本方案优先级，不证明整个机制无效。后续完整训练须另立任务，不在本页自动授权。
- 候选预算不是新增费用或延期授权。认领前按本机实测速度和既有资源窗口确认能完成；4090 仍受 **2026-10-07 00:00 北京时间**截止约束，203 的 Q10 32h上限不转移给新任务。输入、数值、预算或归档失败即留证停止，不重启旧取消队列。

## <a id="q13-t01"></a>Q13-T01：单位化总残差与增量的桥接对照

**问题**：Q10 的增量联合学习若有效，收益是否真的来自去掉预处理响应，而非单位化或其他协议差异？

- 前置：Q10 两臂完整验收，启动代码、初始参数、21576 行增强/索引及头 RNG trace、源选点和评估清单均能复用。新增且只新增一臂 `[f(x),unit(f(x)-f(G(x)))]`；复用 Q10 的原图和增量臂，不继承其训练权重。三者头均 2048→1024→2；Q13 与 Q10 增量臂均保留残差两端及原图直通的梯度，Q10 原图对照仍只对 z 反传。总残差臂共两个 encoder 前向，增量臂共三个，计算差异如实记录。
- 新臂固定 12 轮/21576 更新，沿用 Q10 的源 val 12 次选择以及 source_best/terminal 两权重完整评估。硬上限 **20 GPU小时，含预检、评估和归档；新权重/证据及备份≤6GiB**。实测不满足或配对证据缺失则待前置，不改 batch、缩轮或重训旧对照。
- 唯一主比较为 Q10 增量 source_best 对新总残差 source_best 的源 test，采用共用 CE/AUC/区间判据；相对原图是背景。即使 Q10 相对原图不支持，本项仍可辨别两种残差定义，但不能把相对更好改称已实现提点。
- 查重：[N05](../records/N05-T01.md) 已试总残差 raw/direction/factorized，direction 未显示固定短预算优势；其 2049 维头、2轮和目标末点评估不是本控制。[N07](../records/N07-T01.md) 是 raw 总残差，不能替代单位化桥接。不是再次验证“单位化一定有益”。

## <a id="q14-p01"></a>Q14-P01：同图跨算子响应校准

**问题**：删除 VAE 响应中与同图 blur 响应平行的分量，是否保留更有用的判别变化？Blur 不是预先认定的纯干扰。

- 前置：Q10、Q12 完整验收且可复用；固定 **Q10 joint source_best** 的同一 encoder，不能分别使用 VAE-trained/blur-trained 编码器。令 `rG=f(Px)-f(Gx)`、`rB=f(Px)-f(Bx)`，`p=((rG·rB)/||rB||²)rB`、`e=rG-p`；`rB=0` 时定义 `p=0`，沿用现有数值容差，不按结果删样本。先报告近零响应频率；实际精度使方向不可靠则停。
- 固定五头：`e`、`rG`、被删除的 `p`、使用 label-free 固定错配 donor 的 `e_wrong`，四者各1024维/2050参数；三视图 `[f(Px),f(Gx),f(Bx)]` 是3072维/6146参数的较大参考头，不称同容量。错配在每个源 split 内按视频 ID 排序循环移位一位，不跨 split、不看标签、不含自身。
- 主候选 `e` 须同时优于 `rG` 与 `e_wrong`，使用共用判据；`p`、三视图头是完整报告的替代解释参考。另仅在源 test 固定 `e` 头上作同标签错配推理诊断：每类按视频 ID 循环移位一位，标签仅用于 donor 分组，绝不用于训练头或可部署输入；该诊断也存在联合分布外限制。同图相对该错配诊断须达到共用差值/区间判据才讨论精确同图价值；未达到不能称两者等效。
- 若投影只删除主要标签响应，或改善仅由三视图输入解释，不能宣称“伪造特异性”。本项不同于 [N11](../records/N11-T01.md) 的源域拟合 `r≈z` 后正交化；Q12 是算子替代训练，并非每样本同一特征空间的校准。重建残差、投影或正交本身不宣称新颖。

## <a id="q15-p01"></a>Q15-P01：局部 patch 关系响应

**问题**：重建前后局部关系变化是否比原图关系或单 patch 响应幅度更可读，并依赖真实空间邻接？可独立认领，不等待 Q10。

- 使用 Q04 同一 fresh 预训练 CLIP/初始零更新 LoRA及 VAE、eval，固定最终第24层 patch、既有 post-layernorm，再逐 token L2 单位化得到 `U_P,U_G∈R^(256×1024)`。只读16×16网格右/下相邻的480条边，不做全 Gram 平均、图网络、attention或层数扫描。
- 四个480维/962参数线性头：边上 `U_Pi·U_Pj−U_Gi·U_Gj`；同边 `U_Pi·U_Pj` 原始关系；边两端原始 patch 特征响应 L2 范数均值（post-layernorm后、L2单位化前）；对两视图共同置换256个位置后再计算的关系差。置换固定一次、不看标签，保留配对 token 和响应集合，破坏真实邻接；置换及全部边定义在认领前保存。逐 batch 计算后只保存480维读出，不缓存全体 patch token。
- 关系响应须同时优于原始关系、幅度与置换控制，采用共用判据，才支持本冻结读出下的局部关系价值。若共同置换无损，不支持空间邻接叙事；若幅度头已解释收益，不把关系编码包装成新机制。
- [Q04](../records/Q04-T01.md) 已否定具体 patch 均值读出优于 CLS，但未测试空间关系；本项不重跑层级/均值矩阵。这里只检验这480条邻边，不证明全局 patch 机制或端到端提升；局部重建、图与二阶统计已有先例。

## <a id="q16-p01"></a>Q16-P01：固定中点二阶响应（低优先备选）

**问题**：编码器沿同一次重建连线的非线性响应是否具有一阶差之外的可读判别价值？可独立小预算认领，不替代前三项优先级。

- 使用 Q15 相同 fresh 冻结模型；`M=(P(x)+G(x))/2`，`κ=f(Px)-2f(M)+f(Gx)∈R^1024`。三个1024维等参数线性头：`κ`、中点 `f(M)`、一阶 `f(Px)-f(Gx)`；不增加原图直通拼接。三头共1500更新，使用共用冻结探针协议。
- `κ` 须同时优于中点与一阶控制，采用共用判据；同步报告位移幅度、κ幅度及其源 test 分层表现，分层不重新选点。若收益由中点视图或位移幅度解释，不能声称曲率独有收益；混合图异常仍未排除，阳性结果也不能直接升级端到端训练。
- [Q07](../records/Q07-D01.md) 已测重建路径、有限差分与中点偏离，但未训练此受限读出；[N10](../records/N10-E01.md) 小步修正未支持收益，不能据“更局部”预判有效。`κ` 测的是 **编码器路径曲率**，不是重建器二阶导数或数据流形距离；端点加κ等价加入第三视图，故不以这种 concat 声称新信息。新颖性尚未充分检索，只作为备选假设。
