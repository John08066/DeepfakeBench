- 假设：在残差幅度、头容量及适应训练预算相同的条件下，逐坐标符号仍提供分类收益。竞争解释：符号在LoRA/头适应后冗余，冻结线性头差异主要来自校准或适应不足。
- 对照：`r=z(x)-z(VAE(x))`，`u=r/||r||2`，`z,r:[B,1024]`；signed臂输入`[z,u]`，abs臂输入`[z,abs(u)]`，均`[B,2048]`。同2048→1024→2分类头、初始化、增强后batch与头dropout RNG。VAE冻结，encoder eval关闭dropout但LoRA实际训练。零范数或非有限数立即停止。
- 观察：固定末checkpoint的逐域及宏平均CE/AUC。ΔCE=CE_abs−CE_signed，ΔAUC=AUC_signed−AUC_abs；两者分别≥0.02nat、≥0.01且三域ΔCE均≥0才支持固定预算符号收益。任一宏差≤0则本预算不支持；其他为不确定。这是预注册工程判据，不是显著性检验。
- 查重：4090 N01-T01是在目标选择过的冻结特征上训练五个线性头，不能回答端到端适应；N05-T01正在比较raw/direction/factorized，没有abs臂；203 N02-T01比较VAE/blur。此次signed臂是同时训练的桥接对照，不重复计为新方法、seed复验或独立实验；只算一项配对机制问题。
